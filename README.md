# ZhiZi

Mount & Blade II: Bannerlord 质子交换 Mod。

## V1

- 与目标 Clan Leader 对话发起交换。
- 玩家提供 0-17 岁家族成员。
- 对方提供 18-24 岁未婚、非 Clan Leader 成员；囚犯允许参与。
- 使用原版 Barter 界面，只允许用金币报价。
- 参考原版婚姻价值逻辑计算交换价值。
- 报价达到参考价值时 100% 成功；25%-100% 之间按报价比例曲线决定成功率。
- 成功后双方真实切换 Clan，对方成年成员加入玩家主队，可正常战斗、带队、被俘和死亡。
- 合约固定两年；到期或任一方死亡后归还存活成员。
- 合约数据仅通过 CampaignBehavior.SyncData 保存在当前存档。
- 玩家送出的未成年成员外派期间拦截原版成年教育补点，归还后恢复原版教育补全。

源码实现针对仓库 `Qika2-Source-Decompiled/1.5.0原版` 的相关调用链。
